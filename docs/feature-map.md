# Feature Map

사용자 관점에서 본 프런트엔드 기능 지도. 각 기능을 **어떻게 트리거하는지(마우스/키보드)**, **어떤 규칙이 적용되는지**, **코드가 어디에 있는지**를 적는다.
UI 동작을 바꾸면 이 문서도 같이 갱신한다. 아키텍처와 스타일 규칙은 `CLAUDE.md` 참고.

상태는 모두 메모리에 있으므로 새로고침하면 샘플 데이터로 초기화된다.

## 화면 구성

| 영역 | 설명 | 코드 |
|---|---|---|
| 사이드바 | 스마트 리스트(Inbox, Today, Upcoming, Anytime, Someday, Logbook)와 프로젝트(사이드 프로젝트, 독서) | `components/Sidebar.tsx` |
| 리스트 헤더 | 현재 리스트의 아이콘과 이름 | `components/ListHeader.tsx` |
| 할 일 목록 | 현재 리스트의 todo. Logbook은 완료일별 섹션으로 나뉨 | `components/TodoList.tsx`, `components/TodoItem.tsx` |
| 추가 버튼/입력창 | 새 todo 추가. Logbook에서는 숨김 | `components/AddTodo.tsx` |

화면 폭 720px 이상(`md:`)에서는 사이드바가 왼쪽 240px 열이고, 그보다 좁으면 목록 위쪽에 쌓인다.

## 기능

### 1. 리스트 전환
- **트리거**: 사이드바 항목 클릭. 키보드 단축키는 없다(링크이므로 Tab으로 이동해 Enter).
- **동작**: 클릭한 리스트가 활성화(`aria-current="page"`)되고 헤더와 목록이 바뀐다. 처음에는 첫 번째 스마트 리스트(Inbox)가 활성이다.
- **카운트**: 항목 오른쪽 숫자는 그 리스트의 미완료 todo 수다. 0이면 표시하지 않고, Logbook은 카운트가 없다.
- **코드**: `hooks/useLists.ts`(`selectList`), `List.openCount`

### 2. Todo 생성
- **열기**: 화면 하단의 파란 `+` 버튼(aria-label "새 할 일") 클릭, 또는 `n` 키. `n`은 전역 단축키지만 다른 입력창에 포커스가 있거나 Cmd/Ctrl/Alt/Shift가 함께 눌리면 무시한다. 한글 입력 상태에서도 물리 키(`e.code`) 기준으로 동작한다.
- **입력**: 입력창이 목록 맨 위에 나타나고 자동 포커스된다.
  - `Enter`: 추가하고 입력창을 비운다. 입력창은 열린 채 남아 연속 입력할 수 있다.
  - `Esc`: 입력을 버리고 닫는다.
  - 포커스를 잃을 때(blur): 입력이 비어 있으면 닫고, 내용이 있으면 열린 채 둔다.
- **규칙**: 앞뒤 공백을 제거하고, 빈 문자열이면 추가하지 않는다. 새 todo는 현재 활성 리스트(`listId`)에 속하고 미완료 상태다.
- **제한**: Logbook에서는 `+` 버튼이 없다(`List.canAdd === false`). Today에서 추가하면 `listId`가 `today`가 되므로 마감일 없이도 Today에 보인다.
- **코드**: `AddTodo.tsx`, `useTodos.add`

### 3. Todo 선택
- **트리거**: todo 행 클릭(체크박스, × 버튼, 입력창 클릭은 제외). 선택된 행을 다시 클릭하면 선택 해제.
- **효과**: 배경이 강조되고, 마감일 표시가 날짜 입력으로 바뀌며, 행에 키보드 포커스가 간다(삭제 키 동작용). 한 번에 하나만 선택된다.
- **주의**: 더블클릭의 두 번째 클릭은 선택으로 취급하지 않는다.
- **코드**: `TodoList.tsx`(`selectedId`), `TodoItem.tsx`(`onClick`)

### 4. Todo 완료/완료 취소
- **트리거**: 행 왼쪽 원형 체크박스 클릭.
- **동작**: 체크 표시가 잠깐 보인 뒤 0.5초에 걸쳐 페이드아웃되며 목록에서 사라진다(`LEAVE_DELAY_MS = 500`). 사라지는 중에 체크박스를 다시 누르면 취소되고 원래대로 돌아온다.
- **이동 규칙**: 완료된 todo는 **Logbook에만** 보인다. 원래 리스트와 Today에서는 빠진다. Logbook에서 체크를 해제하면 원래 리스트(`listId`)로 돌아간다.
- **기록**: 완료 시각(`completedAt`)이 찍히고, 해제하면 지워진다.
- **코드**: `TodoItem.tsx`(`handleCheck`), `Todo.toggled`, `useTodos.toggle`

### 5. Todo 제목 수정
- **열기**: 제목을 더블클릭. 입력창으로 바뀌며 전체 텍스트가 선택된다.
- **확정**: `Enter` 또는 입력창 밖 클릭(blur). 한글 입력 조합 중의 Enter는 무시한다.
- **취소**: `Esc`. 원래 제목으로 되돌린다.
- **규칙**: 앞뒤 공백을 제거하고, 비어 있거나 기존과 같으면 변경하지 않는다.
- **코드**: `TodoItem.tsx`, `useTodos.rename`

### 6. 마감일 설정
- **트리거**: todo를 선택하면 나타나는 날짜 입력(`<input type="date">`)에서 날짜를 고른다. 값을 지우면 마감일이 없어진다.
- **표시(선택 안 된 상태)**: 행 오른쪽에 표시한다.
  - 오늘: "오늘"(accent 색, 굵게)
  - 지난 날짜: "N일 지남"(danger 색, 굵게)
  - 그 외: "M월 D일"(muted)
- **Today 연동**: 마감일이 오늘이거나 지난 미완료 todo는 소속 리스트와 상관없이 Today에도 나타난다.
- **날짜 형식**: `'YYYY-MM-DD'` 로컬 날짜 문자열(`models/date.ts`).
- **코드**: `TodoItem.tsx`, `useTodos.setDueDate`, `Todo.isOverdue`, `List.contains`

### 7. Todo 삭제
- **마우스**: 행에 hover하거나 포커스가 있을 때 오른쪽에 나타나는 `×` 버튼 클릭. 터치 기기(hover 불가)에서는 항상 보인다.
- **키보드**: todo를 선택한 뒤(행에 포커스가 있는 상태) `Backspace` 또는 `Delete`.
  - 제목이나 날짜 입력 중에는 동작하지 않는다(입력 중 글자 지우기와 충돌하지 않도록).
- **확인 절차 없음**: 즉시 삭제되고 되돌릴 수 없다.
- **코드**: `TodoItem.tsx`(`onKeyDown`, × 버튼), `useTodos.remove`

### 8. 단축키 도움말
- **트리거**: `Ctrl + ?`(= `Ctrl + Shift + /`). 입력창에 포커스가 있어도 동작한다. 다시 누르거나 `Esc`로 닫는다.
- **표시**: 화면 하단 중앙에 토스트로 단축키 목록이 뜬다. 자동으로 사라지지 않는다.
- **유지보수**: 단축키를 추가/변경하면 `ShortcutHelp.tsx`의 `SHORTCUTS` 배열도 같이 고친다.
- **코드**: `components/ShortcutHelp.tsx`

### 9. Logbook (파생 뷰)
- 모든 리스트의 완료된 todo를 모아 보여준다. 추가 버튼과 카운트가 없다.
- 완료 시각 최신순으로 정렬하고 완료일별 섹션으로 나눈다. 섹션 제목은 "오늘", "어제", "M월 D일", 올해가 아니면 "YYYY년 M월 D일".
- 체크를 해제하면 원래 리스트로 돌아간다(기능 4 참고).
- **코드**: `List.groups`, `TodoList.tsx`(`formatGroupDate`)

## 키보드 단축키 요약

| 상황 | 키 | 동작 |
|---|---|---|
| 새 할 일 입력창 | `Enter` | 추가 |
| 새 할 일 입력창 | `Esc` | 닫기 |
| 제목 수정 중 | `Enter` | 확정 |
| 제목 수정 중 | `Esc` | 취소 |
| 어디서든(입력 중 포함) | `Ctrl + ?` | 단축키 토스트 열기/닫기 |
| 단축키 토스트 열림 | `Esc` | 닫기 |
| todo 선택 상태(행 포커스) | `Backspace` / `Delete` | 삭제 |

전역 단축키는 없다. 위 키는 모두 해당 요소에 포커스가 있을 때만 동작한다.

## 알려진 제약

- 상태가 메모리에만 있어 새로고침 시 초기화된다.
- Inbox, Upcoming, Anytime, Someday는 현재 특별한 규칙 없이 `listId`가 일치하는 todo만 보여준다(Today와 Logbook만 파생 규칙이 있다).
- 정렬·드래그 이동·리스트 간 todo 이동 UI는 없다.
